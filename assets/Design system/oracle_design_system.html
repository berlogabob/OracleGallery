Register Guide

Which system do I use?

The Oracle Design System has two registers — not two separate systems. One visual language, two environments. Read this section first before building anything.

Document Register
Cream — the default
All outputs that exist outside the installation: reports, receipts, the website, academic documents, presentations. Light, legible, unhurried.
Website Reports Thermal receipt Slides Printed materials
Installation Register
Void — contextual only
What appears on the screen inside the physical installation. Used sparingly on the website — only in full-bleed oracle portrait sections.
Installation screen Oracle portrait hero Symbol reference
For Andrey — building the website: Build in the Document Register (cream background, charcoal text). Use the Installation Register only when showing the oracle portrait full-bleed — for example, a hero image section or the symbol showcase. If you're unsure which to use, it's cream.

03

Motion — Web Layer

The oracle is slow, deliberate, ritual. Nothing in this system snaps. Everything breathes. Motion is reserved for interaction responses — never decorative, never on page load.

One exception: a single slow fade-in (--dur-ritual, opacity 0→1) is permitted on the hero/oracle portrait section only.

Duration tokens
--dur-instant
0ms
State changes that must be immediate. Never used for visible transitions.
--dur-fast

--dur-medium
600ms
Component transitions: text fade, section crossfade.
--dur-slow

State crossfades, possession blends. The oracle's primary tempo.
--dur-ritual
4000ms
Oracle-specific reveals. The hero fade-in. Receipt unfold. Reserved for significant moments only.
Easing tokens
--ease-oracle

Primary easing. Weighted, not bouncy. Used for almost everything.
--ease-in-breath

--ease-out-breath
cubic-bezier(0, 0, 0.2, 1)
Settling, releasing. Fast start, decelerates. For exits and reset.

05

The nine conditions

The oracle moves through nine conditions in a defined arc. Each has a distinct emotional tone and visual register. These are not screens or pages — they are the oracle's modes of presence. The visitor does not navigate them. They are moved through them.

STATE 00
IDLE
The oracle rests. Ambient breathing motion only. Waiting for presence.
Quiet · ambient · waiting
STATE 01
AWAKENING
The oracle stirs. Something has approached. The space shifts.
Recognition · summoning
STATE 02
CAPTURE
The visitor's face is read. Alignment required. The oracle sees.
Attention · alignment
STATE 03–06
LISTENING
The oracle opens. The visitor speaks across four turns. Each turn deepens possession.
Open · receptive · accumulating
STATE 07
INSCRIBING
The mark is being drawn. The plotter moves. The oracle has decided.
Completion · mark being made
STATE 08
RECEIPT
The oracle reveals what it understood. The thermal receipt prints. Transparency moment.
Transparency · revelation · document
STATE 09
RESET
The oracle releases. The visitor has left. Return to void.
Release · return
06

How the oracle moves

These rules govern movement between conditions on the web. Forward is deliberate. Reset is slow — the oracle releases, it does not snap. If in doubt: slower is always more correct than faster.

From To Out duration In duration Easing Notes
IDLE AWAKENING --dur-medium --dur-slow --ease-oracle First presence. The oracle arrives slowly.
AWAKENING CAPTURE --dur-medium --dur-slow --ease-oracle Attention narrows. Face alignment begins.
CAPTURE LISTENING --dur-medium --dur-slow --ease-in-breath Opening. The oracle receives.
LISTENING SPEAKING --dur-fast --dur-medium --ease-oracle Response arrives. Faster — the oracle has been waiting.
SPEAKING LISTENING --dur-medium --dur-slow --ease-out-breath The oracle settles back into reception.
SPEAKING (turn 4) INSCRIBING --dur-slow --dur-ritual --ease-oracle Final transition. The oracle moves to draw. Significant — use --dur-ritual.
INSCRIBING RECEIPT --dur-medium --dur-ritual --ease-out-breath The reveal. The document register appears within the installation moment.
ANY RESET → IDLE --dur-slow --dur-ritual --ease-out-breath The oracle releases slowly. Never snaps. The visitor has left.
07

What the oracle is

Language of the Oracle
Use
presence condensed elemental liquid archaic ritual ancient unplaceable pre-technological absorbed acoustic mark
Avoid
stone futuristic digital projected rendered modern AI-generated chatbot holographic

The oracle is no longer described as a stone figure. The portrait imagery is liquid gold — an ancient, elemental presence condensed from something unplaceable. No specific culture or tradition.

The gold token (--gold: #c9a84c) reads as warm ambient light emanating from within the figure, not surface decoration. Gold appears on the website only when something of significance is being communicated.

The oracle portrait exists in four expression states tied to the possession arc: closed → slight open → speaking → fully open. Generative particles are a live installation layer — the web system does not attempt to replicate them, but its motion pacing should feel coherent with the installation's breathing rhythm.

08

The eight marks

Oracle assigns each visitor one of eight marks drawn by a CNC plotter. The mark is determined by a neural network trained on the RAVDESS audio dataset, mapping acoustic features to SVG path parameters. Two visitors who receive the same mark will receive different expressions of it — the geometry shifts with their voice.

Each mark is drawn from an adapted Hobo sign — a pre-digital visual language used by itinerant workers. The reassignment of these signs to emotional states is an intentional act of recontextualisation.
