## 2. Запуск и проверка работы GUI

### Основная цель
Убедиться, что графический интерфейс работает корректно

### Подзадачи
- [ ] **Подготовка к запуску**
  - [ ] Активировать виртуальное окружение `.venv`
  - [ ] Проверить, что все зависимости установлены
  - [ ] Убедиться, что порт 8787 свободен

- [ ] **Запуск приложения**
  - [ ] Выполнить команду `uv run neje-gui`
  - [ ] Дождаться сообщения "NiceGUI ready to go on http://127.0.0.1:8787"

- [ ] **Проверка вкладок**

  - [ ] Убедиться, что контент каждой вкладки отображается корректно

- [ ] **Проверка элементов управления**
  - [ ] На вкладке "Connection": проверить кнопки "Connect", "Disconnect", "Home" и т.д.
  - [ ] На вкладке "Calibration": проверить кнопки тестов и калибровки
  - [ ] На вкладке "Ready": проверить отображение статусов
  - [ ] На вкладке "Exhibition": проверить preview и кнопки управления

- [ ] **Проверка интеграций**

### Возможные варианты выполнения

## 3. Запуск тестов

### Основная цель
Убедиться, что код соответствует требованиям и работает правильно

- [ ] **Подготовка тестового окружения**

- [ ] **Анализ результатов**

- [ ] **Исправление проблем**

- [ ] **Проверка покрытия кода**

- **Вариант C (Инкрементальный):** Запускать тесты после каждого изменения

  - Минусы: Требует дисциплины
